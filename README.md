# Piano Learning – Catalogo

Brani per l'app **Piano Learning** (RC Digital). Questo spazio è **pubblico in sola lettura**:
l'app legge i file da qui, solo RC Digital può aggiungerli o toglierli.

## Regole
- In `brani/` vanno SOLO file MIDI (.mid) o MusicXML (.musicxml, .mxl) di **pubblico dominio** o con
  **licenza libera che permette l'uso commerciale** (CC0, CC BY, CC BY-SA). Mai NC (non commerciale) o ND.
- Conta la licenza del **file**, non solo della musica: un brano di Beethoven trascritto da un sito
  commerciale NON è libero.
- Ogni file va descritto in `catalogo.json` con titolo, compositore, licenza e attribuzione:
  le licenze CC BY / CC BY-SA obbligano a citare l'autore del file.

## Come aggiungere un brano
1. Su GitHub apri la cartella `brani` → **Add file → Upload files** → trascina il file → **Commit changes**.
2. Apri `catalogo.json` → matita ✏️ → aggiungi la scheda del file → **Commit changes**.
3. Entro qualche minuto il brano compare nell'app (tasto «Catalogo Piano Learning»).
